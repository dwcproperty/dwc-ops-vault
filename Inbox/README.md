# Inbox Workflow

The Inbox is temporary capture, not a permanent filing cabinet.

## Process each item

1. Decide whether it is useful, actionable, or disposable.
2. If useful, move the durable idea into a properly named note and link it from here.
3. If actionable, put the action in the owning operational system or a current task list.
4. If it is only historical evidence, label it as such and leave it in the appropriate archive/log location.
5. Empty or duplicate captures can be deleted after confirming they contain nothing important.
