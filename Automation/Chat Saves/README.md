# Chat Saves

These notes preserve useful session context, decisions, experiments, and implementation history. They are historical evidence by default—not current configuration and not a substitute for a maintained SOP.

## Promotion checklist

When a chat save contains durable knowledge:

- Add or update the canonical note.
- Link the chat save to that note using an Obsidian wikilink.
- Record the current status, authority, and last-verification date.
- Move stale or completed material into an archive when it is revisited.
