# DWC-Ops Start Here

This is the entry point for the DWC-Ops Obsidian vault.

## Use this vault for

- Engineering memory, experiments, implementation notes, postmortems, and chat saves.
- Convenience indexes for owners and properties.
- Links to the maintained DWC Systems Knowledge library.

## Do not use this vault as the live system of record

- Live property, tenant, lease, work-order, process, and accounting state belongs in the owning platform.
- Current staff SOPs and reusable business policies belong in the canonical workspace/Notion.
- Never store passwords, API keys, webhook secrets, bank data, SSNs, or raw applicant-screening data here.
