## Why moved

The previous version of this file was the master technical reference for every automation, process, form, service, and integration we'd built. As the team grew, employees needed access to behavior-focused operational docs without seeing repo paths, env vars, and infra detail. The split:

- **Notion SOPs DB** — employee-facing SOPs (one per automation that affects daily work)
- **Notion Owner — Automations Reference page** — owner-only technical reference (repo paths, env vars, debug commands, in-flight items)

Obsidian remains the home for live operational logs (`Automation/<system>/`) and Claude session recaps (`Automation/Chat Saves/`).
